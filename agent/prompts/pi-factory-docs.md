# Pi Factory Documentation

Tampilkan ringkasan dokumentasi Pi Factory dan arahkan user ke file lengkap:

- `~/.pi/agent/extensions/pi-factory/README.md`
- `~/.pi/agent/extensions/pi-factory/USECASES.md`

Ringkas command utama:

- `/pi-autoplan <idea>` — start/refine project + phases.
- `/pi-status` — show status.
- `/pi-create-phase <name>` — create phase scaffold.
- `/pi-plan-phase [phase]` — plan phase only.
- `/build-loop --dry-run` — preview automation.
- `/build-loop --max-phases 1 --verify "<cmd>"` — execute one phase.
- `/pi-decide "<question>"` — multi-role decision.
- `/pi-review <subject>` — multi-role review.
